# Pipeline TypeScript SDK

Instruction builders, account and event decoders, fee maths, discovery and RPC quoting for
the Pipeline router (`PiPEf4fFBpYXCtgfiWgVWzZNXnq2wZ7bnXidJCTwf34`). Built on
[`@solana/kit`](https://github.com/anza-xyz/kit).

> **Placeholder names.** The package name `@pipeline-sol/sdk` and the product name
> are working names and will change before publishing. The package is `private` for now.

Every byte layout mirrors the Rust crates `pipeline-strategy-interface`, `pipeline-client`
and `pipeline-events`. The tests check this against vectors generated by those crates
(`test/fixtures.json`).

## Build and test

Node 20.19 or later.

```sh
cd sdk/ts
npm install
npm run build   # tsc → dist/
npm test        # typecheck, format check, vitest
```

The tests never touch the network. To regenerate the cross-language fixtures after
changing a Rust layout (run from `sdk/ts`):

```sh
npm run fixtures   # cargo run -p pipeline-client --example ts_fixtures > test/fixtures.json
```

## Conventions

- Addresses are kit `Address` strings; instructions are kit `Instruction`s with
  `AccountMeta { address, role }`.
- `u64` and `i64` are `bigint`; `u8` and `u16` are `number`; `Option<T>` is `T | null`;
  `Vec<u8>` is a byte array.
- PDA helpers and instruction builders are `async`, because kit derives PDAs with WebCrypto.

## Usage

### Build a swap

```ts
import { address } from '@solana/kit';
import { amountForBudget, associatedTokenAddress, swap, TOKEN_PROGRAM_ADDRESS, TradeMode } from '@pipeline-sol/sdk';

const trader = address('...');
const inputMint = address('...');
const outputMint = address('...');

// Spend at most 1 token (9 decimals) in total, including Pipeline's 0.25% and a 0.5%
// integrator fee.
const amountIn = amountForBudget(1_000_000_000n, 50);

const instruction = await swap(
    {
        trader,
        strategyProgram: address('...'),
        marketState: address('...'),
        traderInput: await associatedTokenAddress(trader, inputMint, TOKEN_PROGRAM_ADDRESS),
        traderOutput: await associatedTokenAddress(trader, outputMint, TOKEN_PROGRAM_ADDRESS),
        inputVault: address('...'), // from the market account's `vaults`
        inputMint,
        outputMint,
        inputTokenProgram: TOKEN_PROGRAM_ADDRESS,
        outputTokenProgram: TOKEN_PROGRAM_ADDRESS,
        integratorFeeAccount: address('...'), // or null
        strategyAccounts: [], // from resolveAccounts(...)
        inputHookAccounts: [], // Token-2022 transfer-hook accounts, if any
    },
    {
        mode: TradeMode.ExactIn,
        amountIn,
        amountOut: 0n,
        minAmountOut: 990_000n,
        integratorFeeBps: 50,
        extra: new Uint8Array(),
    },
);
```

`inputHookAccounts` in the instruction data is always set from the number of hook accounts
passed. Add the instruction to a transaction with kit as usual, together with a compute
unit limit.

### Discover markets and quote

```ts
import { address, createSolanaRpc } from '@solana/kit';
import {
    fetchMarkets,
    marketViewFromMarket,
    quoteStrategy,
    resolveAccounts,
    TOKEN_PROGRAM_ADDRESS,
    TradeMode,
} from '@pipeline-sol/sdk';

const rpc = createSolanaRpc('https://api.devnet.solana.com');
const [{ address: marketAddress, account }] = await fetchMarkets(rpc);
const market = marketViewFromMarket(marketAddress, account, [TOKEN_PROGRAM_ADDRESS, TOKEN_PROGRAM_ADDRESS]);

const trade = {
    mode: TradeMode.ExactIn,
    inputIndex: 0,
    outputIndex: 1,
    amount: 1_000_000n,
    trader: null,
    extra: new Uint8Array(),
};
const feePayer = address('...'); // any funded account; nothing is signed
const strategyAccounts = await resolveAccounts(rpc, market, trade, feePayer);
const { quote } = await quoteStrategy(rpc, market, trade, strategyAccounts, feePayer);
```

`quoteStrategy` runs the strategy's own `pipeline_quote` by simulation, so amounts are at
the strategy's vaults: Pipeline's fee, the integrator fee and token transfer fees are not
applied (use the fee helpers below). The runtime strips trailing zero bytes from return
data; the SDK pads them back before decoding.

### Decode events

The router emits events as self-CPIs. Decode one instruction's data, or pull every event
out of a transaction fetched with `getTransaction(signature, { encoding: 'json', maxSupportedTransactionVersion: 0 })`:

```ts
import { decodeEvent, extractEventsFromInnerInstructions } from '@pipeline-sol/sdk';

const event = decodeEvent(instructionData); // PipelineEvent | null
if (event?.type === 'Swap') {
    console.log(event.data.netSent, event.data.pipelineFee);
}

const accountKeys = [
    ...tx.transaction.message.accountKeys,
    ...(tx.meta.loadedAddresses?.writable ?? []),
    ...(tx.meta.loadedAddresses?.readonly ?? []),
];
const events = extractEventsFromInnerInstructions(accountKeys, tx.meta.innerInstructions ?? []);
```

### Fee maths

Identical to the Rust `fees` module. All fees round up.

```ts
import { amountForBudget, ceilBps, maxTotalSpend, pipelineFee } from '@pipeline-sol/sdk';

pipelineFee(400n); // 1n
pipelineFee(401n); // 2n
ceilBps(10_000n, 50n); // 50n
maxTotalSpend(1_000_000n, 50); // 1_007_500n, or null on u64 overflow
amountForBudget(1_007_500n, 50); // 1_000_000n
```

### Show and filter on trust facts

`inspectMarket` and `inspectStrategy` read the router's registry, the strategy program, its
metadata, OtterSec's verified-builds API and each mint, and return facts plus flags. There
are no scores and no safe/unsafe judgements.

```ts
import { filterMarkets, inspectMarket } from '@pipeline-sol/sdk';

const facts = await inspectMarket(rpc, marketAddress, { cluster: 'devnet' });
const shown = filterMarkets([facts!], { exclude: ['permanent-delegate', 'transfer-hook'] });
```

OtterSec only covers mainnet. Pass `cluster` so the lookup is skipped elsewhere
(`verifiedBuild.status` is then `not-applicable` and neither build flag is set).
`FLAG_DESCRIPTIONS` holds each flag's exact meaning:

| Group    | Flags                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| -------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Program  | `upgradeable`, `frozen`, `program-missing`, `verified-build`, `unverified-build`                                                                                                                                                                                                                                                                                                                                                                     |
| Registry | `unregistered`, `metadata-missing`, `metadata-unreachable`, `metadata-invalid`, `conformance-report`                                                                                                                                                                                                                                                                                                                                                 |
| Mints    | `mint-unreadable`, `token-2022`, `mint-authority`, `freeze-authority`, `transfer-hook` (a hook is set), `transfer-hook-authority` (can set one), `transfer-fee` (non-zero now or scheduled), `transfer-fee-authority` (can change it), `permanent-delegate`, `non-transferable`, `default-frozen`, `pausable`, `paused`, `closable-mint`, `interest-bearing`, `scaled-ui-amount`, `confidential-transfers`, `permissioned-burn`, `unknown-extension` |

### Strategy metadata and custom actions

`fetchStrategyMetadata(uri)` fetches and validates a strategy's metadata document
(`schema/strategy-metadata.v1.json`; see `docs/STRATEGY-GUIDE.md` section 7).
`buildActionInstruction` turns one of its `actions` into an instruction, and
`buildCreateMarketFromMetadata` turns its `init` into `create_market`.

| `discovery`    | `fetchMarkets`, `fetchStrategies` (`getProgramAccounts` filtered by discriminator)                                                                                           |
| `quote`        | `quoteStrategy`, `resolveAccounts` (RPC simulation), and the instructions they simulate                                                                                      |

| `inspect`      | `inspectProgram`, `fetchVerifiedBuild`, `inspectMint`, `inspectStrategy`, `inspectMarket`, `FLAG_DESCRIPTIONS`, `filterMarkets`: trust facts and filter flags, no judgements |
